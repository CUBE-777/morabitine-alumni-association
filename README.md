# جمعية خريجي ثانوية المرابطين — React (قيد الترحيل)

مشروع React (Vite) لموقع الجمعية، نتيجة ترحيل Phase 3–5 من المشروع الأصلي
(HTML/CSS/JS ثابت). **الموقع العام فقط مُرحَّل حتى الآن. لوحة الإدارة (admin/*)
لا تزال بالبنية القديمة (static HTML) بانتظار الموافقة على Phase 6–7.**

## التشغيل محليًا

```bash
npm install
cp .env.example .env   # ثم عدّل القيم إن لزم (القيم الافتراضية تطابق المشروع الحي)
npm run dev
```

## البناء للإنتاج

```bash
npm run build   # الناتج في dist/
npm run preview # لمعاينة نسخة الإنتاج محليًا
```

⚠️ **لم يُشغَّل `npm install`/`npm run build` فعليًا في بيئة الترحيل** (لا يوجد
اتصال بالإنترنت في تلك البيئة). راجع ملف `MIGRATION_STATUS.md` للتفاصيل الكاملة
وقائمة ما يجب التحقق منه قبل النشر.

## البنية

راجع `MIGRATION_STATUS.md` لشرح كامل للـ Architecture وخريطة كل ملف قديم →
ملف جديد.
